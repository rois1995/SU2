# Proposed independent contracts and implementation semantics

## Mathematical contracts

Approved M1 conservative variables use `(rho, rho*vx, rho*vy, rho*E)` and ideal-gas pressure `(gamma-1)*(rho*E-|momentum|²/(2*rho))`. Gamma is greater than one and the gas constant is positive. The preserved Initialization compatibility theorems connect these conventions and area normals to CFDLean M1; no Roe or characteristic-boundary approval follows from M1.

The protected point specification chooses the input conservative state when admissible and the backup otherwise. With an admissible backup, the resulting primitive fields agree with that selected state's thermodynamics. Rejection is proved equivalent to failure of admissibility in the declared real model. The complete traversal specification `modelPoints` folds this existing contract in increasing point order, retaining the evolving current/primitive state and counting failed **first** attempts. It is separate from the memory executor. Repeated visits also have stateful fold semantics; production traversal visits every allocated point once.

The complete-stage contract requires every allocated row (owned or halo), resets and publishes the failure count, clears all four residual components, preserves truncation, all old cells before snapshot, primitive columns 7–10, characteristic caches and addresses outside the declared writes, then snapshots all corrected current components into old storage. Memory and fluid scratch execution are specified separately. The proposed declarations/types and negative contracts are frozen for external approval; the worker does not grant that approval.

## Memory and execution

Addresses are logical `(block, offset)` pairs, not concrete byte pointers. Blocks 0/1=current/old, 2/3=volume/periodic volume, 4=timestep, 5=residual, 6=truncation, 7=squared-velocity scratch, 8=primitive and 9+marker=characteristic caches. Flow stride is 4; primitive and cache stride is 11. A missing cell is `none`; actual loads can fail. `DataRep` describes the pre-preprocessing input current/old/primitive rows; prior velocity cells may be absent because the operation resets them before reading. It does not assert valid or correctly converted primitive inputs.

`executeVelocity` resets V², loads momentum/density, writes each velocity, rereads that field and accumulates its square. `executeThermo` reads rho and total energy and computes specific internal energy. `executeFluid` follows all seven ideal-gas scratch assignments and the conditional entropy assignment. `executeChecks` runs density, pressure, sound and temperature setters before testing their disjunction. Negative sound² preserves the old sound slot. Fallback loads old conservative components into current one at a time, recomputes all stages, ignores the second check flags as production does, then writes enthalpy. The returned physical flag reports the first trial. The executor never receives a mathematical expected result to install.

The fluid object records parameters, thermodynamic scratch fields and an opaque family of other scalar fields. It is structurally disjoint from point memory. Factory parameters are modeled from CIdealGas's constructor. Selected production STANDARD_AIR uses the default `CompEntropy=true`; the enabled branch is included. The native default-constructor check confirms this dispatch observation. `fluid_overwrite`, `point_fluid` and loop refinement account for shared scratch between visits and both failed and accepted attempts.

`constructor_refines` models the constructor's projection onto represented storage: current/old base zeroing, truncation zeroing, 11-column primitive zeroing, V²/timestep zeroing, conservative seed stores and actual old copy. Unmodeled auxiliary allocations between these operations are explicitly outside this projection. This is not a proof of allocation, real C++ container copy semantics or complete constructor execution. `constructor_backups_admissible` imports M1's guarantee under the explicit primitive admissibility and energy-formula premises.

## Principal result and premises

`preprocessing_snapshot_refines` takes pre-preprocessing DataRep, FluidReady, truncation and cache representations. It proves existence and success of the executed preprocessing and preprocessing+snapshot, derives BeforeSnapshot and BoundaryRep-shaped representations, current storage, bounded/published counters, a fluid snapshot frame and the combined memory frame relative to that original input. `common_refines`, `points_refine`, `point_execution`, `stage_execution` and actual load/store lemmas supply its dependencies.

No admissible-backup premise is required for memory execution. The second-invalid possibility is retained. `complete_admissible` needs admissible old rows and proves admissibility after the complete fold; `complete_primitive_correct` also composes the preserved `set_point_refines` scientific contract for every row under that premise. `preprocessing_tail` proves exact primitive tail preservation for the executed model. All point/column bounds are Fin bounds, with coverage/order/no-duplicate proofs and a 64-bit counter bound requiring `M < 2^64`. `velocity_byte_bounds` and `counter_fits_storage_bounds` reuse the preserved Bounds requirement `8*(M*11) ≤ 2^64`. Concrete allocation sizes, pointer separation and C++ unsigned overflow correspondence still need independent justification.

## Arithmetic domain

The mathematical model uses exact reals, total real division, Real.sqrt and Real.log. Real.log is totalized even when its argument is nonpositive. C++ libm may instead return nonfinite values and affect the floating-point environment; its division, pow, sqrt, reassociation, rounding and flags are not proved equivalent. This difference applies even to a failed first trial later repaired by fallback. The native injected-invalid-backup observation is evidence of the open interface, not a proof of real/IEEE equivalence or a reachable production defect. No hidden positive-temperature restriction is placed on the operational theorems. Scientific positivity conclusions require their stated admissibility premises.
