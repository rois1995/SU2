## Confirmed source behavior; causal hypotheses remain untested

CheckFirstHeight begins curved distance queries at h*1e-4. It refines while the
physical-distance interval straddles height tolerance; it also stops when that
interval proves the requested height is not met. Positive clearance is a separate
requirement. ClosestCurved returns a lower bound over all still-competitive nearest
regions, substituting a pessimistic negative distance where positive normal-side
clearance is not certified. A negative result is not proof of penetration.

Tighter distance precision can sharpen the sign bound but does not guarantee a
positive result. The existing first-height loop is not a general sign-refinement
loop. The diagnostic separately tests h*1e-4,h*1e-6,h*1e-8, within existing local and
shared work/memory/time admission. Signed values at the returned candidate are only
witnesses; no sampling or nearest-candidate sign substitutes for a certificate.

Generic ReconstructWallSplit/ReconstructSplitPatch form wall apices from a flat
triangle centre minus requested height times its normal. Existing
PhysicalFirstHeightProposals instead projects seven barycentric feet to the actual
reference and uses its normals. Those proposals are used by BLFirstRow9,
BLEvent15 and BLGrowth12, but not these generic Common split paths. This difference
can matter on curved faces; it does not yet prove the cause or an admissible fix.
A bounded read-only second opinion confirmed these source facts; no files/jobs were
changed by that agent. Preserve constrained/blended advancement policies in actual
BL construction; this source lead does not authorize replacing direction fields.
