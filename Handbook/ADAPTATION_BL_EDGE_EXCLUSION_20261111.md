  Cubic bounds include all component control points; analytic proxy bounds retain
  their existing certified error. Complete component membership is checked in Build.
- Use the complete current support radius, including normal continuation/fade.
  FIRST_ROW additionally covers the Option-A crease blend radius (and proxy error
  between its original edge and the curved support); exclude both full and base.
- Reuse the donor's conservative segment/box predicate, then existing curved control-
  hull root ADT or faceted proxy ADT. Empty expanded segment-box candidate sets prove
  exclusion; endpoint distances or samples do not. If a broad transition query
  encloses the complete model bounds, the index cannot be empty: fall back without
  gathering a whole wall. No precise nearest point or normal is needed for screening.
- Admit fixed/vector scratch and check/charge the original reservation. Memory,
  work, deadline, nonfinite/unknown padding and uncertain overlap mean fallback;
  sticky original budget failures are preserved, never turned into exclusion.
- Factory callbacks return the incoming flow/background tensor only after exclusion.
  Rounded query points must match the proved segment envelope; other coordinates
  use existing Compose. Profile/support changes invalidate the context and require
  rebuilding integration geometry, avoiding stale {0,1} cuts over a new thin BL.

  and actually bypassed composition samples. They are not accepted mesh progress.
