 everywhere (the DC-14 b3 mesh shows the same pattern, dc15/layer_census_b3.txt).
 ClearAbove vs a real deformation step: ClearAbove is a discrete one-vertex repair - it moves a single FREE blocker along
 one column direction, only when no neighbour column vertex is involved, and the layer of each column advances alone.
 81 % of its refusals (18131 of 22475 in c1) are exactly the cases a deformation handles: the blocker belongs to a neighbouring column front
 (FIXED) or a lone move inverts its star because its neighbours stay (no valid move). A closed advancing-layer step
 (Alauzet-Loseille-Marcum 2017, Algorithm 2) instead prescribes the displacement of the whole active front (every
 active top moves by its law step along its smoothed normal; stopped columns and walls fixed, symmetry planes sliding),
 solves for a smooth displacement of all inner vertices (linear elasticity P1, or a cheaper metric-weighted Laplacian/
 IDW as a first version), moves the mesh in pseudo-time steps with validity freezing (cancel and freeze vertices of a
 cell that would invert or leave the validity window) and connectivity optimisation (swaps) plus smoothing between
 steps, then inserts the layer by splitting the column edges in the room that was made. It replaces ClearAbove and most
 of G's clearance stops, and with the first layer inserted the same way it also removes B1 (no per-lift excess
 certificate: one deformation solve per layer group instead of 19.5k local transactions).
 Acceptance (TODO 3.1): target layer count +-2 on >= 90 % of wall vertices; bad/long at 10-300 h0 strongly lower on the
 full M6; cut regressions accepted.
 Components and sharing (decision: share where useful, parallel-ready = local cavity transactions on owned cells,
 commit as one unit, 2D pattern):
   - displacement solver (P1 elasticity / Laplacian on simplices, CG): SHARED, dimension-generic template over the
     simplex (2 or 3); 2D growth layers need the same room.
   - pseudo-time move loop with validity freeze and one-unit commit per owned patch: SHARED (template on Cell/Point;
     the exact orientation predicate is per dimension behind one interface).
   - connectivity optimisation during the move: DIMENSION-SPECIFIC kernels (2D edge flips; 3D 2-3/3-2/edge swaps) behind
     a shared driver; 3D reuses CNativeOptimize3D.
   - front normals and the symmetry/crease direction rules (n' = n - (n.s)s, blend, D1 law): SHARED math; vertex-normal
     extraction per dimension.
   - validity-only intermediate steps + final gates + deficit report (IndependentValidity, estimated deficits): SHARED
     module to be generalised from BLEvent15 (orientation, face matching, skin manifoldness, first heights).
   - h0 ramp and its config check: SHARED already (CConfig, dimension-free); the 2D engine must consume it.
   - surface-first phase driver with phase timing/streaming: SHARED skeleton, operators per dimension.
   - curved reference (DC-16): DIMENSION-SPECIFIC evaluators (3D PN triangles; 2D curved polyline/spline, CReferenceWall)
     behind one curved-authority interface; the curvature size rule L <= sqrt(8 eps R): SHARED.
   - parallel FIRST_ROW driver: SHARED ownership/commit pattern (port of the 2D one), after the curved wall.
