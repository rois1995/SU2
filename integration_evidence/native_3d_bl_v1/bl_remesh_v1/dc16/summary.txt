2. WHAT WAS BUILT
------------------
 Shared 2D/3D: Common/include/adaptation/CNativeDeformation.hpp (template on D = 2, 3): stiffened P1 vector Laplacian,
   projected PCG with sliding constraints, pseudo-time move with validity freezing (ALM 2017 Alg. 2 step 4) behind one
   per-cell predicate. Tests [NativeDeform16] in 2D and 3D. The 2D engine does not use it yet (2D behaviour unchanged).
 3D room step (BLDeform16.inl, before each layer of G): needy tops (kernel bound < 1.5 x step), free vertices of their
   above stars + 1 ring (registry, below-cell and first-child vertices pinned, role-0 planes slide), Dirichlet =
   planned top steps, solve, move (exact orientation + Euclidean quality floor), metric validity settle (bounded; a
   non-closing settle cancels the move), one-unit interior commit over the complete union of stars, sliding vertices
   one by one through MoveVertex. Event 0: 7 calls, 11.9k needy tops, 31.7k vertices moved, 21 s. ClearAbove kept as a
   local fallback (173 moves, 19 collapses on event 0).
 Joint transactions in G: a clearance refusal whose blocker is a pending planned top widens the transaction (791
   retries, 375 accepted on event 0).
 Validity-only intermediate construction (dc9::validityOnlyConstruction, set only when !final_cycle): R2 lifts without
   MeasurableChanged; Admit12 Layer and Refine (requested edge > 1.6) by cell validity only. Vertex-removing operations
   keep their certificate; final cycles unchanged.
 V: demand queue with an event-wide vertex-tensor cache (geometric edge estimate), cells rescanned by id watermark,
   exact admission unchanged; intermediate cap 900 -> 1800 s; final cycles keep the exact scan (review 8).
 W: selection prefilter by the same estimate (exact integration only above 1.2): 172 -> 65 s. W still splits 0 edges:
   the target asks for none (no curvature term, coarse wall sensor) -> DC-17 curved authority.
 Memory (B6 explained): FrozenField's "Query outside" exception listed every donor (~15 MB per message); G stored the
   stop text per column (~1000 such stops at layer 7) -> 17 GB (34 GB in the killed c2 run). Fixed at the source
   (bounded donor witnesses in CNativeField3D.cpp) and in G (stop texts <= 160 chars). G now 1.95 GB.
 V throughput: the same unbounded witness made each failed measurement cost ~1 s (404 attempts in 360 s on c3).
 Boundary coverage: the imported M6 symmetry "plane" is not planar (y varies ~1e-14); points bound on it were
   realized ~1e-18 outside the donors ("Uncovered source segment endpoint", "No original donor contains a requested
   point"). CNativeNearContainment.hpp: tolerant coverage at the domain boundary (1e-12 x max(1, |x|), and at most
   1e-6 x the donor's longest edge), used after the exact search in FrozenField::Query and edge candidates,
   TraceSegment endpoints (separate constant end pieces, exact pieces untouched) and the donor import (incl. routing
   and midpoints). Constrain also snaps exactly on axis-aligned carrier planes (fast path).
 Publication / reference setup budgets (fixed 2 GiB and work totals blocked the published events):
   FIRST_ROW memory ceiling = max(default, 1.5 x need), capped at 25 % of node memory, one value on all ranks; need =
   max(measured peak RSS, 4 KiB per input cell) before, max(measured, live + ~6 KiB per original donor) after the
   construction; printed. Joint-source column work bound max(10^6, 128 x skin faces), printed.
   REMOVED CORRECTNESS CHECK (coordinator): the exact JointAffineCoverage envelope pair audit (hours on 1.25M cells) is
