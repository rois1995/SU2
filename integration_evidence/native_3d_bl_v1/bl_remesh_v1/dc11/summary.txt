RULE (sect. 2 of the plan; production and harness).
 Refine/split: vertex removal (an old vertex absent and not a certified one-for-one relocation, or no net vertex gain)
 -> strict changed-edge excess decrease (as 2D absorption); otherwise a size insertion (requested split edge > 1.6) is
 accepted on validity + floors with NO excess requirement; a non-size insertion needs added excess 0 and a rise of the
 minimum mean ratio (harness: also no interior edge > 1.8). No cell-count condition. LayerConstruct (R2 single lift and
 fan transaction) without vertex removal: no size certificate (2D HEIGHT has none), changed edges must be measurable.
 R1w: full D.1 Refine admission with the cone request length. Repair/ApexMove/Coarsen/Geometry*: unchanged. Floors:
 first-row children absolute; LayerConstruct others positivity; others min q/J >= min(old min, .20/.05).
 Termination: work/time budgets, sweep cap 64, attempted set (rejection cache keyed by request + unchanged cavity),
 no-commit stall stop; halves guard (split edge, for ColumnSplit max(wall, lid) edge, >= 1.4 so both halves cannot be
 < 0.7); V remeasures each edge before the request. Iteration 2: SplitGrow = 2D SplitPatch cavity growth (consider()).
