Build39, six ranks. The wrapper ended with SIGTERM (-15),1295.38s, unchanged
source/binary/input/helper pins. It is neither an accepted mesh nor evidence of a
native collective defect. No complete quality-stage capture was produced.

The first timed GDB attach on PID3053772 timed out while reading debug metadata.
Later inspection found that worker in STOP state with931.96 CPU seconds while its
peers had1264–1269 CPU seconds. Later attach/detach samples preserved the previous
stop, explaining the apparent vote/release collective skew. Source review found
no concrete collective mismatch in that path. Keep the failed/full-symbol and
successful/minimal-symbol stack attempts and cleanup receipt; do not turn this
into a production MPI fix. A fresh run without attach is required.

Cleanup verified all nine owned wrapper/timeout/MPI/worker processes gone. GNU
timeout and MPI workers use descendant process groups; stopping only the time
wrapper did not terminate them. The owned timeout group was then terminated and
the stopped worker resumed to deliver pending cleanup. Sources were kept unchanged
until every descendant was verified terminal.
