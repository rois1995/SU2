# F3 timer tree review (source attribution only)

## Finding

The current `EngineStats` exposes useful nested diagnostics but does not provide a defensible >=95% exclusive attribution across target, preparation, census, construction, quality, final proof, and transfer. In particular, `other_seconds` is explicitly computed as total minus selected top-level buckets and `layer_seconds` (`CNativeEngine3D.cpp:2018-2025`); it is residual, not a measured phase. Keep it named residual/unattributed. Do not claim the requested threshold from these fields alone.

The generic `Timer` only subtracts child elapsed time from a parent when the caller explicitly supplies a parent pointer (`CNativeEngine3D.cpp:63-71`). Most timers are additive counters with no parent relationship. `CpuTimer` is process CPU time and is not an elapsed-time partition (`:73-80`).

## Overlap and coverage rules for reporting

- Do not sum phase-window elapsed (`surface_seconds`/`interior_seconds`, quality `window_seconds`) with operation timer fields; they span the same work.
- Treat query/composition, edge, geometry, directory, and collective fields as nested diagnostics unless a source scope explicitly subtracts a child from a parent. E.g., `field_composition_seconds` is nested within `field_query_seconds` (`:2378-2381`); layer sub-timers are documented nested (`Engine3D.hpp:194-196`); `planning_seconds` is nested in selection (`:282`).
- `tracked_collective_seconds`, quality `tracked_collective_call_seconds`, and election timers measure tracked calls; they are not wall-wait and can overlap phase envelopes. No timer here isolates time blocked waiting for the slowest rank.
- Final proof (`finish()` geometry/height validation), stage-observer work (`:1901-1918`), and parts of final-vote/report assembly are unassigned to a dedicated exclusive node. Do not roll these into “measured construction” or relabel `other_seconds` as a phase.
- Requested tree can be reported with measured nodes plus explicitly unavailable/uninstrumented nodes and measured residual. The current source does not support a 95% measured exclusive tree without adding instrumentation; this review makes no code changes.
