# B2/B3 minimum implementation contract — scratch only

Use an event-scoped BoundaryGuidanceMemo supplied explicitly to BoundaryGuidance; the default remains uncached. Keep it out of TargetPolicy persistent StorageBytes and the metric-family target_extra_bytes snapshot. One optional bounded reservation is charged once to the RunEvent callerBytes after baseline StateBytes is known, and once to the direct saved-stage fixture options.caller_bytes after geometry/observer scratch is reserved. Choose a fixed share of actual admitted headroom; zero space uses the original path. No cache allocation outside that reservation.

One map by node ID is sufficient. A row retains exact coordinate bits, binding words, six sensor bits, a complete ordered guidance vector, and the ordered strip-rule vector. Different sensor/binding may reuse the strip vector; changed coordinates invalidate both. Cache only contexts with a validated stable parameter association. Validate sensor and the existing authority/node association before a hit; leave nonparameterized or unsupported contexts on the original path. A cached full result is published only after all original side-ownership checks and append/cavity limits succeeded. Never retain partial strip/sample vectors from a throwing call.

A fixed-size event policy stamp includes authority/base/full/Option-A identities, authority handle/version, live base/full sample/geometry/support versions, core/h0, and a strip-generation counter advanced before ConfigureRadius mutates strips. Include marker roles/names exactly. On a changed stamp/roles/names, clear the event map; no per-hit scan of all creases or strips. Existing production writes to Option-A geometry occur before event memo construction or via ConfigureRadius. Existing mutable fixture changes remain on the uncached default; explicit memo tests clear/recreate it when directly replacing raw Option-A arrays.

Account map-node and vector capacity conservatively using existing transfer_memory conventions. Before insertion or replacement, admit temporary copy peak as well as retained bytes. If it cannot fit, keep the original result and skip caching. Returning a cached result still copies the output vector; existing cavity scratch must cover it. The memo is synchronous event state, not a new shared target/geometry authority.

Tests reuse native_boundary_guidance_reference.inc as the independent exact ordered-sample oracle: cold/warm equality; changed sensor, point, binding, metric profile, authority and roles/names; full/strip hit counts; invalid input still rejects before lookup; no stale partial entry after the existing append limit throws; near-zero reservation uses the old path; reserved bytes charged once at pipeline and saved-stage entry. Add the whole connected cheap-group checks before its single A/B reprofile.
