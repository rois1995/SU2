# Required-face diagnostic scope

Rank-local registration means serial G3 has no REMOTE child-attribution gap. It does not prove that every parent bound was already present in the census: a complete imported star can contain an adjacent face not yet measured. The printed new_faces_unknown_parent, children_unmatched, children_unmeasured and observation_failures fields must be reported from the actual run. The above-parent count applies only to measured children with a known finite parent bound; unknowns are never zero substitutes. No claim of complete parent-bound coverage is made before these rows are inspected. The global M26 lane census is a separate measurement with its own exact per-rank reconciliation.

Some draft wording said serial G3 measurement was complete; read that as the absence of a remote registration gap only. The pinned source-check file remains unchanged throughout the active campaign; this reporting clarification changes no code, input, result gate or tolerance.
