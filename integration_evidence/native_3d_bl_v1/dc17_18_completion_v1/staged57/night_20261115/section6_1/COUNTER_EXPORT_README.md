# Accepted N1 counter export helper

`export_accepted_counters.py` prepares M18 engine-exit fields, M20 quality-window/private-round rows, and M21 ownership-memory boundary rows for both events. It reuses `p7p8_r3_20261115/check_connected_events.py` for event parsing and existing hard gates. It deliberately adds no log regex scanner.

Run `python3 export_accepted_counters.py --self-check` for the fixture-only schema/omission check. Before any rank log is read, the helper validates `status.json`, `full_workflow_receipt.json`, `section6_1_reference_identity.json`, and both existing event/timer gate receipt pairs. It requires terminal exit 0, all owned handles terminal, unchanged inputs and source/binary pins, accepted workflow, and accepted identity. Then invoke it as `python3 export_accepted_counters.py CASE --output PATH`. The receipt validation is the helper trust boundary; do not launch it until the primary confirms the full run is terminal. Missing M18 fields stay null and are listed by name. Missing M21 before/staged/committed records appear as `not_emitted` rows with null measurements, never zeros.

M18 values are taken from each rank's final `NATIVE3D_STAGE stage=exit` row selected by the existing event parser. They are not replaced with final rebind/ownership counters. Every emitted row carries event, rank, log path, SHA-256, and source line where resolvable. M20 keeps quality windows and private rounds as separate marker records. M21 preserves the printed memory/exchange fields by boundary. The attached per-event gate summary omits raw M20/M21 diagnostic lists because those rows are exported separately.
