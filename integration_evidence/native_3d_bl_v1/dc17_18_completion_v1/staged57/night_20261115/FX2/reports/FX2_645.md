# FX2 mobility-policy replay, build645

Starting commit `c843610249` and build640. The verified [order](../inputs/FIXED_PARTS_2.md) and [SHA256](../inputs/FIXED_PARTS_2.sha256) are archived with the [whole-item source check](../source_check.md). The check found no production assignment to a live mapped authority.

The memo keys entries by shared ownership and stored object address, and matches angle bits, roles and floating-point environment. It keeps the derived policy bytes and the work increment. A permitted replay charges the same storage and work through the existing mobility timer, then compares the bytes. A possibly limiting budget takes the original derivation path. If copying the cached bytes cannot allocate, it also takes that path. An entry keeps only a weak authority handle. Expired handles are removed under the memo lock, which is released before a charge or build.
