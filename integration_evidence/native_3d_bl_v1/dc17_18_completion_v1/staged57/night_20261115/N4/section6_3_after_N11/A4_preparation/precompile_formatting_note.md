# A4 precompile draft corrections

The first draft fragments used mechanically joined `ContextValue` declarations. Their aliases were left at column zero, and adjacent replacements could touch at `;ContextValue`. Before any compile/use, the draft was regenerated from the frozen Ownership base, adjacent declarations were grouped in the binding manifest, and each new data fragment was formatted by clang-format inside a balanced nested wrapper at the original scope depth. The existing statement RHS and operation order were retained; no original function body, lambda, RAII declaration, or evaluation-level local was formatted or moved. The round and slot for-header text remains functionally the same; their body aliases are at the original body indentation.

Review also caught a class-wiring mismatch in the earlier draft: the private declarations were `RoundState` / `SlotState`, but the out-of-line constructor/destructor definitions used `EngineRound` / `EngineSlot`. Definitions now match the declared class names. `EngineContext.hpp` includes the private type headers for visibility but contains no `RoundState` or `SlotState` members. The only instances are the intended locals in the original round and slot for-initializers; no second persistent context object is introduced.

The earlier preformat patch, binding manifest, base-hash record, and primary reversal receipt are preserved verbatim under `preformat/`. The current artifacts are a separate unapplied draft. `shadow_reversal_receipt.json` records a temporary-directory patch application followed by scoped manifest reversal to byte-identical original CPP and Context files. `patch --dry-run` also passed against the current frozen Ownership base. No production file, pinned helper, build, test, or running job was changed or launched.
