# Primary review of the frozen B6 draft

The primary read all twelve generated methods, the header, all three caller sites, and the source/proof generator. This review applies to the frozen B4-bound draft in FROZEN_SHA256.json; production application must wait for B5 acceptance and a rebinding proof against that accepted main file.

The tail chain preserves the earlier original owners: cost vectors, vertex-star map and shared CLocalFailure remain in EstimateOwnership; pending Owned/Selection/directory and PartitionStats remain in MigrateOwnership; outgoing and constant received records remain in MigrateCertificates. Children return before parents unwind, in the original reverse destruction order. Restored swaps affect the same canonical working/source/Selection objects. The staged observer runs before swaps; the committed observer runs afterward and only for quality, as before.

The per-cell helper preserves traversal, reserve order, all arithmetic and geometry calls. Its early return corresponds only to the original untouched-volume continue. Geometry cost remains a double, with the same local length-array scope and estimates; it does not add a cell query or geometry snapshot. Weight maxima, demand reductions, benefit/cost calculations, participation maximum and the declined-migration time update retain order. Scalar value parameters are immutable POD snapshots; mutable transaction payloads and the shared failure are references.

WithinTime retains every original deadline call and short circuit. Context aliases borrow already-active optional slots at the original call sites; the new methods are private to the included implementation. The PhaseOwnership enum qualification avoids collision with the member name and denotes the same existing enum. No quality rule, eligibility threshold, admission operand, query, vote, clock, output row or counter was added or removed.

Requested draft cleanup is complete: accurate implementation-purpose comment, explicit EngineContext forward declaration, const started aliases and removal of the three unused normalization scalar arguments. Existing optional fields and deleted copy/move special members remain unchanged. Actual formatted bodies are recursively inverted and token-compared to the removed lambda, and the whole main reverses byte-for-byte; method sizes are 14–60 lines.

B5's actual observer is EngineControl::ObserveProgress(context, working, atlas_budget, stage). B6 must borrow the originally selected atlas budget explicitly, with entry PhaseOwnership(context, quality, atlas_budget), and use that accepted observer directly when rebound. This draft review is not numerical qualification or an efficiency claim.
