## Dependencies and lifetime constraints

- `EngineSetup` members in exact declared order (`EngineSetup.hpp:5–15`): `admission`; optional `timer_session`, `d9_profile`, `wall_counters`, `lane_counters`; optional `private_parameters`, `private_geometry`, `local_atlas_budget`, `restore_budget`, `atlas_geometry`, `target_geometry_lease`. Its constructor/destructor are defaulted (`EngineSetup.cpp:4–5`); copy/move are deleted. Optional owners are activated only at their current `.emplace()` points. `admission` captures the prior shape policy on construction and restores it at destruction.
- Setup aliases: `atlas_budget` references either the caller-owned `options.shared_geometry_budget` or `setup.local_atlas_budget`; `restore_budget.budget` is non-null only for the shared budget. `geometry` later aliases atlas geometry, private geometry, or `accepted_geometry` (current Adapt line 1507). The lease and atlas geometry must die before budget restoration; setup member order currently preserves that.
- Before geometry resolution, mapped parameter preparation can return a rejected result directly at 1503–1506; that path does not run the later setup blocks or `finish`. Do not attribute that return to a `ready`/finish path.
- Canonical refs: `result` owns `stats`; `stats` aliases `result.stats`; `Selection` constructed at 1527 retains the same stats, resolved geometry, and `options.wall_heights`; `source` retains `world` and `working`; `directory` retains `world` and `geometry.Parameters()`. These identities are shared across the setup blocks and later loop.
- First setup-block anchors follow PART1 S10–S19 ordering: S10 option agreement and initialization; S11 working-surface refresh; S12 applicability; S13 region construction; S15 first-row layer; S18 frontier seeding; S19 initial census. Later Control state (quality windows, transaction capture, timing flags, and `ready`) is used by the subsequent setup/lifecycle/report path as indicated in the table; do not infer a new call or earlier initialization from the older snapshot's line numbers.
- `EngineSetup` now owns the pre-geometry D9 and wall/lane counter objects. Their instrumentation/reporting remains at current Adapt call sites; counter scope does not imply decision ownership. No new unit context fields are inferred here.
