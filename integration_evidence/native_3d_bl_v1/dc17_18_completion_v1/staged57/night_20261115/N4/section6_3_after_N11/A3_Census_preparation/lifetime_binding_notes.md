# Census local lifetime and binding notes

Scope: current A3 Control candidate, validation pending; no proposed restructuring in this note. See `current_field_manifest.md` for declarations, source hashes and current local order.

- `Selection` is constructed only after `EngineContext` has bound the resolved `geometry`; it stores references to that geometry, `stats` (`result.stats`), and `options.wall_heights`. Census and queues share the same `selection` object. The callbacks/lambdas use it by reference; do not replace it with a copy or a second census-owned instance.
- The optional Control values `generation_window` and `generation_window_count` are activated through `ContextValue` at current local points 1576–1579. Those automatic wrappers outlive the subsequent locals and reset the context optionals during Adapt exit. `result_lifetime` is created before `Selection`, so selection and later census readers are destroyed before the result optional is reset. `EngineContext` itself was created earlier and is destroyed after all these local wrappers.
- Census locals are interleaved with other unit state, not one contiguous block: `Selection` (1570), edge report values (1573–1574), generation-window wrappers (1576–1579), edge reuse maps (1580), `field_identity` (1583), and seed lists/cursor (1616–1617). `MeasurementBatch` (3076) is declared later immediately before `measure`, so its scope and initialization point differ from the long-lived state.
- `generation_census`, `generation_debt`, `measure`, and `seed_next` are `[&]` lambdas. Their references close over `selection`, `edge_progress`, `edge_census_round`, retired/campaign maps, `field_identity`, `initial`, `seed_slot`, `working`, `stats`, `geometry`, and the existing setup aliases. Keep these objects alive through every invocation and preserve their referent identity.
- The atlas elapsed-time callback is a special capture: `atlas_budget.within_time=[started,maximum=options.maximum_seconds]` captures the start time and limit by value at 1495–1497. `started` itself is exposed from `ContextValue` as a const reference to `setup.control_prefix.started`. The capture is a snapshot and must remain so; it must not become a dangling reference to a scope wrapper.
- Current raw `decltype` use in `CNativeEngine3D.cpp` is `decltype(checkpoint.blocked)()` at 3515 in rollback. It couples rollback reset syntax to the checkpoint member type; it does not refer to a Census field. No `decltype(selection...)` use was found. Keep this in mind if moving the checkpoint type or its member.
- `EngineContext.hpp` currently has no Census member. `EngineControl` still stores generation-window state while Census candidates remain locals. This is a documented current arrangement, not a design decision in this note.
