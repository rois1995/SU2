## Initialization and lifetime dependencies to preserve

1. Setup/RAII prefix begins before geometry resolution; mapped-parameter failure returns a rejected result before the context construction point (current source lines 1422–1447). `EngineContext` is intended to be built only after `geometry` is selected at 1449. Do not route that early return through `finish()`.
2. `geometry` is the selected atlas/private/accepted reference. `Selection` binds it, `directory` binds `geometry.Parameters()`, and `source` binds `working`; use those same resolved/canonical objects.
3. Preserve declaration/destruction order. Current order puts `working`, then `selection`, then `directory`, then `source`; reverse destruction ends source before directory and directory before selection/working. Geometry owners and setup RAII outlive those references. The shared-budget restore runs after geometry lease/atlas releases; shape admission restores last.
4. The source inventory groups are intentionally cross-coupled: `Selection` is shared Census/Queues; `working` is Ownership but borrowed by Exchange; `directory` is Exchange but swapped by Ownership/checkpoint logic; `result/stats` are Control but `Selection` retains the stats reference. These are ownership/lifetime facts, not justification to duplicate or merge state.
5. `bytes()`/`real_bytes()` are result-sensitive. Keep the original containers, capacities, type sizes, options caller bytes, batch bytes, Session reserved bytes, geometry scratch subtraction, and admission/vote order exactly as currently accounted.
