### Whole-item source check

Checked on `e1d9db1c17`, before the first production edit. The verified measurement text is [MEASUREMENT_M29.md](../inputs/MEASUREMENT_M29.md).

- `NativeRemeshRun.inc::ApplyMetric` invokes the final worker refinement. Its invalid result rejects the adaptation. The public completion flag is assigned later in the outer finalizer, after the live worker census has been released, and may also be cleared by the final memory check. **Reading used:** pass an internal print-only flag on final worker refinement and use the worker's globally rejected result in `EngineControl::EmitFinalRowsAndMove`, after `ObserveProgress("exit")` emits a complete quality census and before the private cells move out. M29 covers rejections at that point on the owning worker communicator. An earlier refusal without an exit census or a later output/outer memory refusal cannot expose that census at the point of refusal. Provisional surface preparation and direct engine checks do not enter the hook.
- The text calls all Part A gates completed events. G2 and GQ stop at measured prefixes, G1 includes intentionally rejected direct engine calls, and G3 is an independent wall fixture. **Reading used:** run the prescribed gates with the existing references and verify M29 is absent, using the final worker event flag rather than treating fixture exits as events.
- `EngineReports::PrintStuckCells` iterates `Selection::census.cells` by cell ID and limits its print to eight. Its predicate is shared with M29. Both use the terminal cache. The measured q, J, shape hinge debt and certified lengths come from `CellState` and `EdgeState`. **Reading used:** emit the fixed local order 01,02,03,12,13,23 used to enumerate tetrahedral edges (`CNativeMetric3D.cpp`, `CNativeDonor3D.cpp`). Resolve each pair to its unordered ID key in the census. The map's global ID sort order varies with tetrahedron vertex order.
- `EngineCensus::MeasureCell` uses `ValidateMetricPatch` with the current-nodal field. `CavityMetricSource::ImportCellsFrom` retains the current nodal sensors for measured cells. `FrozenField::QueryImpl` uses `EvaluateCavitySample` at `Centroid(cell)` and applies the existing optional `MetricComposition`. A valid nonoverlapping tetrahedron contains its own centroid and is its own winning donor. Use the published sensor array and those same accessors for the tensor, and check it reproduces the cached q and J using `Measure`. The check supplies no production decision. The stored `m` values are the raw nodal sensors.
- `RepairLadders::ProposeMove` can propose constrained motion; `ConstrainMovePoint` constrains bound physical-face vertices and, in the composed wall case, the opposite requested-first-height apex. **Reading used:** `free` means unconstrained interior motion as explicitly specified, including globally visible face and height incidence. A fringe vertex can be constrained by a face of another cell outside the two-level dump. Include constraint IDs in the second plain exchange and defer cell serialization until they arrive. The two mesh scans remain unchanged in purpose, and the same constraint flag is printed for every copy of a vertex.
- `CPassiveComm::Allgatherv` uses the passive MPI path without World accounting or round timers. Both exchanges are confined to rejection. Scratch sets, counts and stream buffers are local diagnostics; no Session, census cell, repair demand, or traveling table is extended.
- The N18 F production change at `6b56b42f16` consists of the three specified paths. Part B applies only these changes in a separate diagnostic checkpoint. The existing full controller provides the frozen six-rank workflow and first rejection stop. Only the authorized four diagnostic comparisons apply. Default restoration rechecks all source pins on a fresh build.
