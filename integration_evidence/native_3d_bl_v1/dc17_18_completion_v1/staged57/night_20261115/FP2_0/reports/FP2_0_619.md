The first witness on wing entity `0/10154/2` had a four-sample value of 6.90663e-5 and a Classify value of 9.87378e-5. Both distance values were within tolerance. The local entity check failed independently.

The reviewer order and input SHA256 values were verified. OUT1 used the version 9 accepted surface. IN1 used the version 7 sidecar, the original mobility and entity setup, and the FP0 B tensor rows matched by binary64 coordinates. The experiment used one process per measurement and no volume mesh.
