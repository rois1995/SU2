# RCFD2 real CFD with changed metric settings

R-SM and R-SG used the existing build647 solver, SHA256 `b824f37ee37f2458d334b3534569078437f0a321a4b4166e52288ee111e46b4c`. Before each launch, the production diff against `4730bd59ec` was empty and the build647 fixture, lab and binary pins verified. Each run used both local adaptation options and the same 500-iteration limits as R-S. R-SM set the minimum size to 0.003 and the norm to 2. R-SG retained those settings and changed gradation from 1.3 to 1.6. The fixed 50,000 complexity target, zero Hessian-noise setting, flow configuration and standing workflow checks were preserved. [Order](../inputs/REAL_CFD_2.md) · [Source check](../source_check_rcfd2.md) · [R-SM configuration](../run_sm.cfg) · [R-SG configuration](../run_sg.cfg)

The C1 scoped supervisor finished and its evidence was pushed as `142f3e8751` before the RCFD2 launches. The continuation resumes at its full OFF proof under the same build647 pins. This measurement accepts no mesh.

## Result

R-SM passed both remeshes, both 500-iteration cycles and isolated restart. The density residual fell three orders from its peak at iterations 391 and 193 on cycles 1 and 2. The final mesh has 88,424 points and 423,547 cells. [R-SM run receipt](../G5/build647/SM/run_receipt.json)

R-SG **FAILED** event 2 with two unresolved q violations and one J violation on rank 1. Event 1 passed, and cycle 1 completed 500 iterations. The controller stopped at the rejection. Cycle 2 and its isolated restart are unavailable. The ordered settings were kept, and the failed run was preserved without a repeat. [Read-only diagnosis](RCFD2_SG_diagnosis.md)

Both variants changed the event-1 mesh and sidecar relative to R-S. R-SG also differs from R-SM for both files. The measured metric density maxima were `3.7037e+07` on each available R-SM and R-SG cycle. Missing entries below correspond to the rejected R-SG event or stages that follow it.
