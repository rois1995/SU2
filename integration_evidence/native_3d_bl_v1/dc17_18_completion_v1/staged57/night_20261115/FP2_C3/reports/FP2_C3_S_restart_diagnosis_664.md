# FP2-C3 build664 S isolated-restart diagnosis

The single read-only diagnosis found the first differing gate in the isolated-restart wrapper. The CFD child exited 0 and all observed processes were reaped, but `runtime_receipt_written` was false (expected true). The resource gate passed, with 884,408,320 bytes summed from six process peaks. The supervisor exited 1 because it had no complete live runtime observation.

The runtime sampler recorded plain `[Errno 5] Input/output error` about seven seconds after restart launch. The source covers executable/process mappings and ELF file reads. The logged exception does not identify the read site. An EIO can occur while reading a just-changed process mapping. The wiring error is the sampler's permanent error latch: one incomplete sample set `runtime_error`, which disabled later sampling even though the verified CFD process stayed active for another 43 seconds. All on-disk input and source pins still verified after exit. The error was a missing observation, with no inode or digest mismatch reported.

The correction saves an EIO sample as incomplete and allows the existing loop to take its next full sample. It still requires one complete verification of all six executing inodes and loaded ELF hashes, preserves all non-EIO failures and uses the same isolated-restart validator, process audit and 600-second limit. If no later sample succeeds, the gate still fails. Only the isolated restart is repeated once with the same six sealed adaptation payloads. The original two-event S run remains the observation.
