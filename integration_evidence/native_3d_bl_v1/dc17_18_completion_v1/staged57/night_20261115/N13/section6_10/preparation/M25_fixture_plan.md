## Per-edge measurements

For each input edge, resolve its endpoint nodes from the loaded `BoundaryParameterState`; use the canonical edge and endpoint point coordinates. Call `PredictGeometrySplit(edge, endpoints, *scoped_geometry, tau)` once with a fresh `AtlasBudget` populated with the D9 work, workspace, integer and held-memory settings and `within_time` callback. Record `complete`, `before`, `after`, `evaluated_faces`, elapsed seconds and the budget work delta.

Independently reconstruct the proof using only the public calls identified in `source_binding_inventory.md`: `PrivateParameters(Patch{}, &budget)`, `BindNewPoint` with `Node{UINT64_MAX, arithmetic_midpoint}`, the two incident facets, `ContainsFace`, and `SurfaceDeviation(..., SurfaceQueryNeed::Magnitude(), true)`. Follow the production sequence literally: incident faces in `IncidentFaces(edge)` order; each parent vertices in `face->v` order; parent score before children; left then right child; canonicalization by minimum face id; same double midpoint coordinate expression; same `long double` excess, product and accumulation expression; and the same short circuit on the first failed query. For a complete row require exactly six successful face evaluations and bit equality (`==`) between the independently accumulated `before` and `after` values and `PredictGeometrySplit`'s values. An incomplete prediction is recorded as incomplete; do not invent missing bounds or claim the bit-equality check passed for it.

Store two parent bounds and four child bounds in their production score order. Also store the `BindNewPoint` bound coordinates, Euclidean distance from that point to the arithmetic chord midpoint, and edge length. Record explicit validity flags for failed binding/query paths rather than substituting zeros. Query exceptions follow the production path's semantics: rethrow allocation, length/work exhaustion, and sticky geometry failures; ordinary invalid-argument refusal yields an incomplete measurement. Do not make incomplete rows appear as successful self-checks.

For the wall-law measurements, invoke `EstimateWallEdge` on the three edges of each incident face, anchored to that face facet: six calls per input edge. The common trial edge appears once for each face anchor; each of the four other edges appears once. Use endpoint nodes from `state->Find(id)->node`; retain each edge ID, estimate and support flag so the parent-face comparison can be audited. `EstimateSaysNeed` is only a reported comparison at `tau`; it does not influence geometry prediction or any decision.

## Strict arithmetic and self-check

The independent sum helper must use test-only strict floating-point options because the unit-test target enables fast math while production predictor sources are in the strict `SU2AccurateSum` library. Proposed placement is limited to `M25Score` and `M25Reconstruct` in `m25_fixture.proposed.inc`, compiled only as part of the unit test: under GNU GCC, bracket just that helper with `#pragma GCC push_options`, `#pragma GCC optimize ("no-fast-math", "no-unsafe-math-optimizations", "ffp-contract=off")`, and `#pragma GCC pop_options`. Keep the helper outside any broad pragma scope. Do not modify production code, `Common/src/meson.build`, root Meson flags, or global test flags. The recorded build environment uses GCC; this proposal relies on GCC local optimize pragmas and keeps the exact bit-equality check.

The helper must preserve expression order, not merely compute an algebraically equivalent score. For every complete row, assert `manual_before == prediction.before`, `manual_after == prediction.after`, and `manual_evaluated_faces == prediction.evaluated_faces`. Emit a specific row/edge diagnostic on the first mismatch. Keep this self-check independent of the summary aggregation and run it before writing a row as checked. The expected limit and all D9 atlas budgets stay unchanged; the 60-minute M25 deadline is the only outer run limit.
