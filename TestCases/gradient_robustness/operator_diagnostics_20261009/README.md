These are numerical diagnostics, not production settings or validated RANS improvements.

`operator_probe.cpp` runs the actual SU2 LS/WLS/GG routines, SIMD MUSCL reconstruction, and SIMD edge-normal gradient correction on prescribed fields: x+2y, x², xy, y², radius, sin(pi*(x-2y)). It also compares the existing primal adaptation quadratic fit, labelled `quadratic_sensor`; its weighted fit/stencil selection is not the unweighted quadratic method of Diskin & Thomas. The probe requires serial execution and MGLEVEL=0. It advances no CFD solution.

Gradient, midpoint reconstruction, projected viscous-gradient, per-edge affine quadrature and assembled affine convection errors are reported separately. Independent integration over median-dual segments must reproduce the affine divergence. The integrated geometric moment A*S from Bellosta et al. restores affine flux integration; checks cover facet orientation, area normalization and contraction indices. For exact Cartesian quadratic gradients, the native viscous edge correction must retain the midpoint derivative. These checks do not establish nonlinear stability or solution convergence/order.

The launcher generates n12/n24 regular, rotated straight stretched and curved stretched meshes, both alternating quad/triangle and triangle-only. Inputs and raw diagnostic output remain local. The probe can also read a supplied RANS configuration with MGLEVEL=0; its polynomial fields are geometry checks, not RANS convergence evidence.

`face_tangent_probe.patch` changes only the SIMD compressible interior viscous flux for 2D: average gradient minus its edge-direction discrepancy times n_hat/(dx dot n_hat). The approximate thin-layer Jacobian uses the same projected distance. This implements the Avg-LSQ(FT) form described by Thomas, Diskin & Nishikawa, equations 11 and 14-15. Nearly perpendicular/nonpositive projections retain the original EN operator; all measured faces in these controls have positive projections. Gradient computation, SA production/scalar fluxes and all 3D paths remain unchanged. No full gradient-dependent Jacobian or production scalar/AD/boundary integration is claimed. Apply only to the matching robustness source and preserve/restore an immutable production binary.

`inviscid_flux_probe.patch` implements the integrated interior correction from Bellosta et al., equations 10-11, and the chain rule from Nishikawa (2022), equations 27-30. Its explicit guard permits only static 2D unlimited-MUSCL `MMS_NS_UNIT_QUAD`, whose boundary states are imposed strongly. The correction contracts the geometric moment A*S with the Euler flux derivatives; do not multiply it by area again. It evaluates the chain rule in SU2's stored primitive variables T,u,v,p at their arithmetic reconstructed average, deriving rho and its differential from rho=p/(R*T). Roe stores only four gradient variables in this setup: never read a density-gradient row. This primitive-variable choice and WLS reconstruction differ from the papers' rho-based linear-LS examples and must be disclosed when comparing results. Geometry is recomputed on each call for this small diagnostic; no production performance claim follows. The approximate implicit Jacobian is unchanged; the native Newton-Krylov comparison is a separate trial. Weak boundary closure (Bellosta equation 12), limiter coupling, general fluid models and full AD/parallel integration are outside this patch. Do not use it as a RANS improvement.

`viscous_source_isolation.patch` is a causal diagnostic, not a proposed discretization: with 2D flow GG gradients, WLS reconstruction and MUSCL enabled, only the interior compressible viscous flux consumes the reconstruction gradients. Flow vorticity/strain used by SA production, boundary gradients and the SA scalar gradients retain GG. The recorded ordinary-SA test uses the supplied adapted RANS boundary-layer mesh and the same restart/settings as the previous GG-all control. Its growing residuals with zero interior floor points separate global failure from SA clipping; they do not establish a complete cause.

Apply each patch separately to the matching production source, compile with one low-priority worker, save the resulting binary under a distinct immutable name, and restore the source before the next experiment. The handbook contains local campaign paths, binary hashes, measured results and outstanding validation. The first flux prototype had an invalid density-gradient access: its CFD results are explicitly discarded. This directory contains only source/reproduction notes; raw histories and states remain local.

`assess_mms_restart.py case.cfg fields.csv` measures final all-node RMS/max conservative-variable errors against the existing `CMMSNSUnitQuadSolution::GetSolution`, using its exact coefficients. It accepts dimensional 2D NS/MGLEVEL=0 data and rejects inadmissible states and unsupported units/dimensions. This avoids mistaking the early printed MMS block for final error: SU2 prints verification errors only at inner iteration 1 and every 40 screen-output intervals. Native two-step continuations of settled restarts independently check the Python error calculation. Unit checks cover the known native origin state, a density perturbation and invalid/unsupported inputs. Raw reports remain local; the helper computes errors even for unconverged states, so convergence still needs separate verification.
